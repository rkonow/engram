Import rows

        
JSON Lines (an object per line), a JSON array of objects, or CSV or TSV with a header row. Columns go to the fields of the same name, and columns the schema lacks are skipped and listed. A row whose key is already here replaces that row. In CSV an empty cell is empty, a list is a|b|c or a JSON array, and a vector is a JSON array. Embedded vector fields are computed from their source fields by the server's model. Up to 256 MB a file; for more, use strata-server import while the server is stopped.

        

          

          

          

        

        
Or paste rows
          
          
as JSON Lines, a JSON array, or CSV with a header row

        

        

      

      

        
SQLite

        
Import a SQLite database: each of its tables goes into the table of its name here, which is created from SQLite's declarations and values when this database lacks it (types, the key, references, NOT NULL and DEFAULT), and its rows replace the rows with their keys. Preview shows each table's schema and what does not carry over, and writes nothing. Up to 256 MB a file; for more, use strata-server import while the server is stopped.

        

          

          

          

        

        

        

        
Export writes this database to a SQLite file that any SQLite program reads: the rows, keys, references, an index on each filterable field, an FTS5 index over each table's text, and the Strata schemas, which an import here restores. Vector indexes, analyzers and Strata's ranking have no SQLite form and stay behind; the vectors go as F32_BLOB columns.

        

          

          

            
            
            

          

        

        

      

      

        
This table's schema

        
In the short form that --schema takes. A database's schema is set when it is created. To change it, design a new one below and copy this database's rows into it with --copy-from, which also embeds again the vectors whose model or source fields changed.

        

      

      

        
Design a schema

          

        
Text is searched by words (BM25), keywords match exactly and can be counted, numbers filter, sort and sum, a vector finds similar rows, edges link rows to other rows by key. A vector field can embed text fields itself: on the collections measured, one vector of title + description together scored best, and searching it together with the text did better still in 8 of 9 runs (the measurements).
